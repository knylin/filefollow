A SMALL WINDOWS TOOL

FileFollow guide

A small panel that floats in a corner of your screen. Switch to any file and it jumps to that file's folder. A second tab keeps everything you copied or cut.

GETTING STARTED

Open it once and forget about it

  • 1

    Double-click FileFollow.exe
    The panel appears in the bottom-right corner, and a blue folder icon appears in the system tray.

  • 2

    Right-click the tray icon → Start with Windows
    From then on it starts by itself.

  • 3

    Work as usual
    Switch to Word, Excel, ArchiCAD or a PDF, and the panel follows to that file's folder.

EVERYDAY ACTIONS

Once you have found the file

Drag out to upload

Drag a file onto a browser upload area, Gmail or a chat window. Ctrl-click to drag several at once. Dragging copies; the original stays where it is.

Double-click to open

Double-click a file to open it in its default app, or select it and press Enter. Double-clicking a folder goes into it.

Paste into a chat or email

Select files and press Ctrl+C (or right-click → Copy files), then press Ctrl+V in the chat box. The files are attached.

Jump to a parent folder

Click the grey path. The menu lists every level, so you can jump to Clients directly instead of clicking Up again and again.

HOW IT FINDS THE FILE

Apps it follows

AppHow
Word, Excel, PowerPointAsks Office which document is open. Files on OneDrive are mapped back to your local sync folder.
ArchiCAD, NotepadFor files opened by double-clicking, reads the path the app was started with.
AutoCAD, Notepad++The window title already contains the full path.
Everything elseLooks up the file name from the window title in the Windows Search index and picks the most recently modified match.

When you switch to a window with no file behind it, such as a browser, a chat app or File Explorer, the panel stays where it is. That way it does not jump away while you drag a file into a browser.

The fastest way: paste straight where you are typing

  1. With the cursor where you want to paste (Word, a chat, a browser), press Ctrl+Alt+C

  2. The clipboard history opens. Pick an item with ↑ ↓, or start typing to search

  3. Press Enter to paste it back where you were. Shift+Enter pastes plain text; Esc cancels

TROUBLESHOOTING

If something seems off

The panel doesn't follow a certain app

The file may be outside the Windows Search index (an external drive or the Temp folder), and the app doesn't show the path in its title. Open an issue naming the app.

Ctrl+Alt+F or Ctrl+Alt+C already does something in an app I use

The panel's shortcuts take priority. In Word, for example, Ctrl+Alt+F normally inserts a footnote.

I don't want something recorded

Content that password managers mark as private is skipped automatically. For sensitive work, choose Pause clipboard recording in the tray menu.

Where is the history stored?

Only on this computer, in %APPDATA%\FileFollow\clips\. Up to 300 entries are kept; older ones are removed automatically, except pinned ones.
