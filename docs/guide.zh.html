WINDOWS 小工具

跟檔夾 操作說明

浮在螢幕角落的小面板。切到哪個檔案，它就跳到那個檔案的資料夾；另一個分頁記下你複製、剪下過的內容。

開始使用

打開一次，之後就不用管它

  • 1

    雙擊 FileFollow.exe
    面板出現在右下角，右下角的系統匣也會多一個藍色資料夾圖示。

  • 2

    系統匣圖示按右鍵 →「開機時自動啟動」
    以後開機就會自己出現。

  • 3

    照常工作
    切到 Word、Excel、ArchiCAD、PDF，面板就跟著跳到那個檔案的資料夾。

常用操作

找到檔案之後

拖出去上傳

按住檔案拖到瀏覽器、Gmail、LINE 的上傳區。可以先按住 Ctrl 點選多個檔案一起拖。拖曳是複製，原檔不會被搬走。

雙擊開啟

雙擊檔案就用預設程式開啟，或選好後按 Enter。雙擊資料夾會進到那個資料夾。

貼到 LINE 或信件

選取檔案按 Ctrl+C（或右鍵「複製檔案」），切到 LINE 對話框按 Ctrl+V，檔案就送出去了。

跳到上層

點灰色路徑，選單會列出每一層，點「客戶」就直接跳過去，不用一層一層按上一層。

    剪貼簿分頁 每次「複製」或「剪下」都會自動記一筆，最新的在上面。

  2. 2

    搜尋 可以搜尋內容、檔名，或來源程式（例如輸入「Chrome」）。

  3. 3

  4. 4

  6. 6

    「含格式」 從 Word 或網頁複製的文字會連粗體、表格一起保存。

  7. 7

    雙擊放回剪貼簿 之後在任何地方按 Ctrl+V 貼上。

最快的用法：直接貼到正在打字的地方

  1. 在 Word、LINE 或瀏覽器裡，游標停在要貼的位置，按 Ctrl+Alt+C

  2. 面板跳出剪貼簿紀錄。用 ↑ ↓ 選擇，或直接打字搜尋

  3. 按 Enter 就貼回剛才的位置。Shift+Enter 只貼純文字，Esc 取消

收起來

用不到的時候

  • •

    收起 按右上角的 —、按 Esc，或按 Ctrl+Alt+F。面板會縮成只顯示資料夾名稱的小膠囊。

  • •

    展開 點一下膠囊，或再按一次 Ctrl+Alt+F。

  • •

    移動 按住膠囊拖到任何位置。靠哪個螢幕角落，展開時就從那個角落長出來。

  • •

    自動收起 系統匣選單打開「自動收起」後，滑鼠移開就收，移到膠囊上就展開。

疑難排解

遇到狀況時

切到某個程式，面板沒有跳

那個檔案可能不在 Windows 搜尋索引的範圍內（例如外接硬碟、Temp 資料夾），而且程式標題沒有寫路徑。告訴我是哪個程式，我再補上偵測方式。

Ctrl+Alt+F 或 Ctrl+Alt+C 在某個程式裡原本有用途

面板的快速鍵會優先。例如 Word 的 Ctrl+Alt+F 原本是插入註腳。如果會衝突，可以換成別的按鍵組合。

不想記錄某些內容

密碼管理員標記為「不要記錄」的內容會自動略過。要處理機密資料時，可以從系統匣選單「暫停記錄剪貼簿」。

紀錄存在哪裡

只存在這台電腦：%APPDATA%\FileFollow\clips\。一般紀錄最多 300 筆，超過會自動清掉最舊的（釘選的除外）。
